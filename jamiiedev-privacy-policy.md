# Privacy Policy — Postiz (Personal Instance)

Last updated: 2026-08-22

This application ("postiz_tik") is a personally operated, self-hosted instance of the open-source Postiz software (https://github.com/gitroomhq/postiz-app), used solely by its single operator to schedule and publish their own social media content.

## Data Collected

This app accesses only the TikTok account data necessary to authenticate the operator and publish content on their behalf, including basic profile information and video upload/publish permissions granted via TikTok OAuth.

## Data Use

Data obtained through the TikTok API is used exclusively to authenticate the account and to schedule/publish the operator's own content. It is not sold, shared, or disclosed to any third party.

## Data Storage

All data is stored in a private database running on infrastructure controlled solely by the operator. No data is transmitted to any external analytics, advertising, or third-party service.

## Third-Party Access

No third party has access to the data processed by this application. It is not a multi-user or public-facing service.

## Data Retention & Deletion

Data is retained only as long as needed to operate the scheduling tool and is deleted upon disconnecting the TikTok account from the application or upon request by contacting the operator.
